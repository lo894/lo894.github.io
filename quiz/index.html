高数 · 20 分钟 · 5 题
1ε-N · 化简
设 an = n + 13n − 2，把下面这个式子化简成一个干净的分式：
|an − 13|
只写化简，不用写 N。看两处：分母的 3 有没有漏，绝对值最后有没有变成正的。
看答案
|an − 13| = |3(n + 1) − (3n − 2)3(3n − 2)|
= |53(3n − 2)| = 53(3n − 2)
分子：3n + 3 − 3n + 2 = 5（注意 −(−2) 是 +2，这里最容易写成 −2）。
n ≥ 1 时 3n − 2 ≥ 1 > 0，分母是正的，所以 5 本来就是正数，绝对值直接去掉。
21 的无穷次 · 快法
limx→0 (1 + 3x)1/x = ?
这是 1∞ 型。把指数凑成标准形状，不要硬算。
看答案
这是 1∞ 型，套 (1 + u)1/u → e，这里 u = 3x。
先把它凑成标准形状：
(1 + 3x)1/x = [ (1 + 3x)1/(3x) ]3
方括号里整体趋于 e，所以
原式 = e3
口诀：1∞ 就把指数改造成「分母跟括号里的尾巴一样」。 这里是 3x，所以指数要写 1/(3x)，但原来的指数是 1/x，差了 3 倍，外面补一个 3 次方。
3递推数列 · 三步
x1 = √2，xn+1 = √(2 + xn)。 证明它收敛，并求极限。
三步：有界 → 单调 → 取极限。先猜出上界是多少（试算前两项就能看出来）。
看答案
① 猜界。算前两项：√2 ≈ 1.41，√(2 + 1.41) ≈ 1.85，还在涨，但不会超过 2。猜上界 2。
② 证有界。x₁ = √2 < 2。若 xn < 2，则 xn+1 = √(2 + xn) < √4 = 2。故对所有 n，xn < 2。
③ 证单调增。要证 √(2 + t) > t（当 0 < t < 2）。两边平方：2 + t > t²，即 t² − t − 2 < 0，即 (t − 2)(t + 1) < 0，t < 2 时成立。
单调增 + 有上界 → 收敛。设极限为 L。
④ 取极限。L = √(2 + L) → L² − L − 2 = 0 → L = 2 或 L = −1。
因 xn > 0，舍去 −1，得 L = 2。
最后那句「因 xn > 0 舍去负根」不能省，否则等于有两个答案。
4无穷小比较
当 x → 0 时，1 − cos x 与 x²2 是什么关系？
三档：高阶、同阶、等价。判断依据是两者比值的极限。
看答案
是等价无穷小。
直接引用基本等价式：1 − cos x ~ x²2（x → 0）。
「等价」的意思就是两者比值的极限是 1：
limx→0 1 − cos xx²/2 = 1
三档判据：比值 → 1 叫等价；→ 非零常数叫同阶；→ 0 叫高阶。
常用等价：sin x ~ x、1 − cos x ~ x²2、ln(1 + x) ~ x、ex − 1 ~ x。
5换元 · 回代
limx→0 e2x − 1x = ?
换元之后别忘了把原变量代回去。
看答案
令 t = 2x，则 x = t/2，x → 0 时 t → 0。
原式 = limt→0 et − 1t/2 = 2 · limt→0 et − 1t = 2
这题就是老毛病：换元成 t 之后，最后一步要写 t 的答案，也要写回 x 的答案。只写一半算没做完。
